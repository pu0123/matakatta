# 03 画面の実装

見た目の正解は `docs/mockup.html`。色・余白・文字の大きさはここから取る。
計算はすべて `src/core/` を使い、画面側で計算し直さない。

## 前提
- React + TypeScript。UIライブラリ・ルーター・状態管理ライブラリは足さない。CSS は素の CSS（`src/styles.css` 1枚＋必要なら画面ごと）
- Vite の雛形（`App.css`, `index.css`, `assets/react.svg`, `public/vite.svg`）は消す
- スマホ幅が基本。PC では幅 420px で中央寄せ
- `<html lang="ja">`、`<title>あといくら</title>`
- 色は `:root` の CSS 変数で定義し、`@media (prefers-color-scheme: dark)` で暗い配色も用意する
- 金額は `font-variant-numeric: tabular-nums`、表示は `¥12,345`（`Intl.NumberFormat('ja-JP')`）
- 絵文字・グラデーション・影の多用・アニメーションの多用はしない。押した感触程度の transition だけ
- ボタンは `<button>`、入力欄には label を付ける

## 型の追加
- `Expense` に `note?: string` を足す（任意のメモ）。core のテストが通ったままであること

## 保存（src/storage.ts）
- `localStorage` に1キー（`atoikura:v1`）で `{ settings, expenses, incomes }` を JSON 保存
- 読み書きは必ず try/catch。読めなければ初期設定画面から始める
- 画面からは `useStore()` のような1つのフックで読み書きする（`src/useStore.ts`）
- テスト：壊れた JSON・空・正常の3通りで読み込みが落ちないこと（`src/storage.test.ts`）

## 画面
画面切り替えは state で持つ（URL は変えない）。戻るボタンで前の画面へ。

### 0. 初期設定（settings が無いとき）
mockup の「最初に3つだけ」。
- 給料日：1〜31 の select と「月末」（月末＝31 として保存）
- 手取り：数値入力（`inputMode="numeric"`）。説明「先月の額でOK」
- 固定費：「合計｜内訳」切り替え。内訳は「名前・金額」の行を足し引きでき、合計を表示
- 貯金：「金額｜割合」切り替え。割合は 0〜100
- 余ったら：「貯金へ｜次の月へ」
- 下に **次の給料日（M月D日）まで使えるお金** を出す。
  初期値は `(手取り − 固定費 − 貯金) × 今日から次の給料日までの日数 ÷ 期間の日数` を切り捨て。
  「今の残りに合わせる」を押すと金額を直接直せる（これが `initialFree`）
- 「はじめる」で保存。`startedAt` は今の日時、`weekStartsOn` は 1
- 手取りの値は、`startedAt` を含む期間の **次の期間** の Income としても保存する（次の給料日に見込みとして使うため）
- 設定画面（ホームから開く）でも同じフォームを使い、値を直せる。`startedAt` と `initialFree` は変えない

### 1. ホーム
mockup の通り。`current()` の結果を表示する。
- 上：区間の日付（「10月27日（月）〜 11月2日（日）」。区間なので給料日で切れることがある）
- 「今週あと使えるのは」＋大きな数字（`week.left`）。
  負のときは数字の代わりに「**¥1,200 オーバー**」を `--minus` の色で出し、「来週の分から引かれます」と添える
- 1日あたり（`perDay`）と、あと何日か
- 進み具合の棒（spent / budget。budget が 0 以下なら満杯で表示）と「使った ¥…｜今週分 ¥…」
- 「給料日（M月D日）まで あと ¥…」（`period.left`）
- お知らせ欄（該当するものだけ、上から順に）
  - 新しい期間が始まっていて、その期間の収入が未入力（`isEstimate` かつ最初の期間ではない）→「給料日の額を入れてください」→ 4へ
  - `overcommitted` →「固定費と貯金が手取りを上回っています」→ 設定へ
  - 振り返り待ちがある →「先週の振り返りが N件 残っています」→ 3へ
- 右上に小さく「記録」（一覧へ）と「設定」
- 一番下に大きな「使った」ボタン → 2へ
- **現在日時が `startedAt` より前**（端末の時計が戻った等）のときは計算せず、「日付を確認してください」とだけ出す。`current()` は例外を投げるので必ず避ける

### 2. 入力
- 自前のテンキー（1〜9, 00, 0, ←）。最大7桁。0円では「記録する」を押せない
- 金額の下に「記録すると今週あと ¥…」を、入力に合わせてその場で出す
- メモ欄（任意、placeholder「メモ（なくても可）」、最大30文字）
- その下に過去のメモの候補を最大6個。**使った回数の多い順**、同数なら新しい順。押すとメモ欄に入る
  （候補の並びを出す関数は純粋関数にして `src/noteSuggestions.ts` とテストを置く）
- 上部に「今日｜昨日」の切り替え（昨日なら日時は昨日の同時刻）
- 「やめる」で何も保存せずホームへ
- 記録したらホームへ戻り、下部に「¥780 を記録しました　取り消す」を5秒出す。取り消すで削除

### 3. 振り返り
- `pendingReview()` を古い順に1件ずつ表示：日時、金額、メモ（無ければ「メモなし」と薄く）
- 「要った｜要らなかった」で verdict を付けて次へ。「あとで」で中断してホームへ
- 下に「先週なくてもよかったお金 ¥…」（先週の区間の `unneededTotal`）をその場で更新
- 全部終わったら「先週の振り返りは終わりです」と、要らなかった合計・件数を出してホームへ戻るボタン

### 4. 給料日
mockup の「給料日です」。
- 直前に終わった期間（`closedPeriods()` の最後）の自由なお金・使った・余り（または超過）を表示
  - 余り：toSavings なら「¥… → 貯金へ」（`--ok`）、carryOver なら「¥… → 次の期間へ」
  - 超過：「¥… オーバー → 今期から引かれます」（`--minus`）
- 今期の手取りを入力（初期値は見込みの額）
- その下に「次の給料日までの自由なお金」を入力に合わせて出す（固定費・貯金を引いた額、と内訳を一行で）
- 「これで始める」で今期の Income を保存してホームへ

### 5. 記録一覧
- 今の期間の支出を日付ごとに新しい順。金額・時刻・メモ・verdict（要らなかったは小さく印）
- 行を押すとメモの修正と削除ができる（削除は確認を1回挟む）
