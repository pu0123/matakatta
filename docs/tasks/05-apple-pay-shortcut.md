# 05 Apple Pay からの半自動記帳

## 仕組み
iPhone の「ショートカット」アプリには、ウォレットのカードで支払ったときに動く自動化（トリガー「取引」）がある。
金額と加盟店名を受け取れるので、それを URL に入れてこのアプリを開かせる。
アプリは URL の値を入力画面に入れた状態で開き、本人は「記録する」を押すだけにする。

**勝手に記録はしない**。必ず入力画面を経由して本人が押す（誤作動や二重起動で記録が増えるのを防ぐため）。

## URL の形
```
https://buy-again.pages.dev/?amount=<金額>&note=<加盟店名>&via=shortcut
```
- `amount` は必須。`note` は任意。`via` は今は表示の切り替えにだけ使う
- 公開先が変わっても動くよう、ドメインやパスに依存しない（`location.search` だけを見る）

## 金額の読み取り（`src/shortcutParams.ts`、純粋関数＋テスト）
ショートカットから渡る金額の書式は端末設定で揺れるので、広めに受ける。
- 全角数字・全角記号は半角に直す
- `¥` `￥` `円` `JPY` 空白 を除く。桁区切りの `,` を除く
- 小数点があれば **小数点以下を切り捨て**（`780.00` → 780。数字以外を全部消すと 78000 になるので注意）
- 結果が 1〜9,999,999 の整数でなければ「読めなかった」として扱う
- `note` は前後の空白を除き、30文字に切る。空なら無し
- テストに入れる例：`780`, `¥780`, `￥１，２８０`, `1,280円`, `780.00`, `780.5`, `JPY 780`, `0`, `-500`, `abc`, 空, 10000000

## 画面の動き
- 起動時に URL に `amount` があれば、ホームではなく **入力画面** を開く
  - 金額欄とメモ欄に値を入れた状態。メモ候補・今日/昨日の切り替えは今まで通り使える
  - 上部に小さく「Apple Pay から」と出す（`via=shortcut` のとき）
  - 金額が読めなかったときは空の入力画面を開き、「金額を読み取れませんでした」と1行出す
- 値を読んだら **すぐ `history.replaceState` で URL からパラメータを消す**（再読み込みや戻るで二重に入らないように）
- 初期設定がまだのときは、パラメータは捨てて初期設定画面を出す
- 「やめる」でも記録せずホームへ

## 設定手順のページ
設定画面の一番下に「Apple Pay と連携する」を置き、押すと手順の画面を出す（新しい画面 `screens/ShortcutGuide.tsx`）。
文言は下をそのまま使う（です・ます調、短く）。

1. 「ショートカット」アプリを開き、下の「オートメーション」→ 右上の「＋」
2. 「取引」を選び、使っているカードを選ぶ。「すぐに実行」にする
3. 「新規の空のオートメーション」→ アクション「URL」を追加し、下の URL を貼る
4. URL の中の `金額` と `加盟店` の部分を、それぞれ変数「金額」「加盟店」に置き換える
5. アクション「URL を開く」を追加する

- 貼り付け用の URL をコピーボタン付きで出す：
  `{location.origin}{BASE_URL}?amount=金額&note=加盟店&via=shortcut`
  （コピーは `navigator.clipboard.writeText`。失敗したら文字列を選択状態にする）
- 「試しに開く」ボタン：`?amount=780&note=テスト&via=shortcut` を開いて入力画面を確認できる（記録はされない、押さなければ）
- 注意書き（そのまま）：
  - 「iPhone の Apple Pay で払ったときだけ動きます。PayPay などのコード決済や、カードを差して払った分は記録されません」
  - 「ショートカットから開くと Safari で開きます。ホーム画面に追加したアプリとは記録が別になるため、連携を使う場合は Safari で使ってください」

## ついでに直す
- 縦が短い画面（高さ 600px 程度）で、初期設定の「はじめる」が「今の残りに合わせる」に重なる。
  下のボタンは固定せず、内容の後ろに置く（内容が短ければ画面下に寄る）形にする。給料日・設定画面も同じ作りなら同様に
