# 04 動作確認で見つかった直し

ブラウザ（375px幅）で全画面を通して触った結果。上から優先。

## 1. App.tsx を分ける
981行あり読みにくい。動作は変えずに分ける。
- `src/screens/` に画面ごと（Setup, Home, Entry, Review, Payday, History）
- 金額・日付の整形は `src/format.ts`
- `App.tsx` は画面の切り替えだけ

## 2. 金額の入力欄（初期設定・給料日）
- 今は `¥` が左端、数字が右端に離れている。`¥` は数字の直前に付けて右寄せにする
- 入力中も3桁区切り（`98,000`）で表示する。保存する値は数値
- 数字以外は受け付けない（全角数字は半角に直す）

## 3. 記録直後の「取り消す」が「使った」ボタンに重なる
- お知らせを「使った」ボタンの **上** に出す。表示中も「使った」を押せること

## 4. 振り返り
- 見出しは「振り返り」にする（先週より前の分も出るため）
- 下の集計は「今回の振り返りで要らなかったにした合計」にし、ラベルは「なくてもよかったお金（今回）」。押すたびに増えること
  （今は先週の分しか数えないので、古い支出を判定しても ¥0 のまま動かない）
- 「何に使ったか思い出せなくても大丈夫」はメモが無いときだけ出す
- 終わった画面の見出しも「振り返りは終わりです」に

## 5. 給料日画面の見出し
「戻る」と見出しが横に並び、説明文が見出しの下で字下げされている。
他の画面と同じく、「戻る」を上の行に置き、見出しと説明文は左端を揃える。

## 6. 記録一覧
日ごとのカードの下の枠線が欠けている（overflow か border の指定漏れ）。全カードで四隅と枠線が揃うように。

## 7. ホームのマイナス表示
- 「今週分」の予算が0以下のときは「今週分 ¥0」と出す（「今週分 −¥16,000」は意味が取りにくい）
- 期間の収入が見込みで、しかも見込みの元になる収入が1件も無いとき（income 0 の見込み）は、
  「固定費と貯金が手取りを上回っています」を出さず「給料日の額を入れてください」だけを出す
